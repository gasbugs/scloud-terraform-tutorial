# SAT와 AI 학습 운영 · 20분 영상 6편

**제작안: 6편 × 20분 = 120분.** 실제 20분 녹화·재생 시간은 아직 검증하지 않았다. 이론은 AI 학습 전체 흐름과 서비스 선택까지 다루고, 화면 실습은 Training Job 기능과 보존된 Job 결과만 사용한다. 토의·발표·개별 작업 대기는 영상 길이에 포함하지 않는다.

| 편 | 고유한 질문 | 핵심 콘텐츠 | 화면 근거 |
|---:|---|---|---|
| 1 | 어떤 학습을 어떤 데이터로 재현할 것인가? | 학습 생애주기, train/validation/test, 데이터·모델 revision, seed, 사용자·플랫폼 책임 | SAT 상품설명회, 원본 demo input-manifest.json·run-config.json |
| 2 | Training Job의 입력·출력과 설정을 어떻게 연결하는가? | 원본 스토리지→마운트→이미지·Command→결과, GPU·노드·권한, 제출 전 점검 | 원본 demo 상세·결과 파일, 저장된 Training Job 생성 화면 |
| 3 | 같은 Training Job을 Spot으로 실행하면 무엇이 달라지는가? | 자원 대기·회수, 화면의 Failover 제한, 체크포인트 간격·복원 조건, 코드 오류와 GPU 장애 구별 | 저장된 Spot 생성 화면, checkpoint-10, 공식 기능 설명 |
| 4 | 실행 성공과 실패를 어떤 증거로 진단하는가? | 상태→상세→로그→모니터링, 원본 demo·텍스트 Job의 경고·학습·업로드, 미보존 자료 | 두 Job의 실제 상세·로그 |
| 5 | 결과가 좋아졌고 추론에 넘길 준비가 됐는가? | 텍스트·이미지 전후 지표, 이미지 혼동행렬, 원본 demo의 개선 없음, 모델·전처리·설정 인계 | before/after·comparison·confusion_matrix JSON, 모델 파일·학습 코드 |
| 6 | 실무 요구에 어떤 서비스를 선택하는가? | SAT·SageMaker·Bedrock의 코드 자유도·입출력·Spot·운영·이동성·비용 | 공식 근거 비교표와 세 요구사항 사례 |

## 통폐합 기준

- 기존 1·2편의 AI 학습 흐름과 재현성은 **1편**으로 합쳤다. 입력 경로의 실제 연결은 **2편**에 둔다.
- 기존 입력·출력 시연과 On-Demand 생성 폼은 **2편의 Training Job 설정**으로 합쳤다. On-Demand는 별도 서비스가 아니라 이 Job의 학습 형태 예시다.
- **3편**은 같은 Training Job을 Spot으로 바꿨을 때의 차이만 다룬다. 일반 Job 설정을 다시 설명하지 않는다.
- **4편**은 실행 증거, **5편**은 성능과 추론 인계를 다룬다. Completed를 품질 향상으로 해석하지 않는다.
- **6편**에서만 SAT·SageMaker·Bedrock을 상세 비교한다.

## 제작 판정

[녹화 구성안](TEACHING_GUIDE.md)의 각 5분 장면은 새로운 개념 또는 실제 파일 증거를 포함해야 한다. 먼저 2편 또는 5편을 시범 녹화해 실제 재생 시간과 설명 밀도를 확인한다. 20분을 채우지 못하면 검증 가능한 콘텐츠를 보강하거나 5편으로 더 합친다. 발화 반복·무음·시청자 응답 대기로 시간을 맞추지 않는다.

로컬 사이트는 교육용 구현이며 화면의 H100 80GB는 실습 시나리오 명칭이다. 보존된 학습 결과는 이 화면에서 실행한 SCP SAT Job이 아니다. 실제 실행 출처는 강사용 구성안에 기록한다. 현재 기능과 비교의 한계는 [SERVICE_COMPARISON.md](SERVICE_COMPARISON.md)에 둔다.
