# SAT Training Job 녹화 강의 · 20분 × 8차수

**영상 8편, 편당 실제 러닝타임 20분, 총 160분.** 시간표의 모든 구간은 강사 설명과 화면 시연으로 채운다. 토의, 대기, 수강생 발표, 개별 실습 시간은 영상 길이에 포함하지 않는다. 따라 해 볼 작업은 영상 밖의 선택 과제로 둔다.

| 차수 | 영상 시간 | 한 편에서 끝낼 핵심 내용 | 화면 시연 |
|---:|---:|---|---|
| 1 | 20분 | SAT 관리형 Training Job의 구성과 책임 범위 | 데이터·이미지·명령·GPU·출력 흐름 |
| 2 | 20분 | 원본 demo의 입력·출력 경로 매핑 | 원본 파일, 마운트, Command, 결과 위치 추적 |
| 3 | 20분 | On-Demand Job 생성 옵션 | 저장된 폼의 필수 필드와 요약 검토 |
| 4 | 20분 | Spot 생성과 중단·재개·GPU Failover·체크포인트 | Spot 폼의 Failover 표시와 적용 조건 |
| 5 | 20분 | Job 상태와 증거별 진단 순서 | 상태별 상세·모니터링·로그 확인 순서 |
| 6 | 20분 | 원본 demo와 한국어 텍스트 Job의 상세·로그 | 시작·학습·종료 근거 추적 |
| 7 | 20분 | 텍스트·이미지 Job의 평가, 결과 파일, 모니터링 | 표본 수·전후 지표·모델 파일·시계열 유무 |
| 8 | 20분 | SAT·SageMaker·Bedrock 실무 선택 | 세 요구사항에 비교표 적용 |

## 중복 방지 기준

- 1차수는 AWS 제품별 장단점을 비교하지 않는다. 이 판단은 8차수에서 한 번 다룬다.
- 4차수에서 Spot 회수, GPU 하드웨어 장애, 체크포인트를 설명한다. 5차수는 이 개념을 재강의하지 않고 상태별 증거 탐색에 적용한다.
- 5차수는 평가 수치를 제시하지 않는다. 정확도와 파일은 7차수에서 판독한다.
- 2차수는 입출력 **경로**, 6차수는 실행 **로그**, 7차수는 **결과의 의미**에 집중한다.

## 제작 및 검증 기준

[강사용 스크립트](TEACHING_GUIDE.md)의 0–5, 5–10, 10–15, 15–20분 구간은 모두 연속 발화와 화면 동작이다. 표의 시각은 **편집 목표**다. 녹화 리허설에서 실제 재생 시간을 측정하고 설명과 화면 전환을 조정해 각 영상을 정확히 20분으로 만든다. 무음 대기나 시청자 응답 시간으로 길이를 맞추지 않는다.

로컬 화면은 교육용 구현이며 표시된 결과는 보존된 AWS G6 실행 기록이다. SCP SAT에서 실행한 결과라고 소개하지 않는다. 제품 비교의 근거와 불확실성은 [SERVICE_COMPARISON.md](SERVICE_COMPARISON.md)에 정리한다.
