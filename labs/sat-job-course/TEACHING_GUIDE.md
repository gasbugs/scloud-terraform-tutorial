# 강사용 스크립트와 실습 · SAT Training Job 8차수

20분 × 8차수, 총 160분. [시간표](CURRICULUM.md)와 [발표 교안](SLIDE_DECK.md)을 함께 연다. **학습자에게 새 GPU Job 실행을 요구하지 않는다.** 로컬 사이트는 SCP 화면을 참고한 교육용 구현이며 저장된 AWS G6 실행 결과를 보여 준다. SAT 제품 자체의 처리 결과로 소개하지 않는다. 1·5차수 이론은 `scp_sat_videos/` 전사와 [실무 비교](SERVICE_COMPARISON.md)의 공식 자료를 바탕으로 한다.

## 시작 전 강사 점검

- [목록](http://127.0.0.1:8080/local#jobs), [원본 demo](http://127.0.0.1:8080/local#jobs/b669419947d55d6991620cdf9bbcaa1f/details), [텍스트 Job](http://127.0.0.1:8080/local#jobs/2dd8760c5b7b55dc8d440c0d18ad2a4e/details), [이미지 Job](http://127.0.0.1:8080/local#jobs/cb0e433e77965ac9ad283d14027ed2df/details)을 각각 연다. 서버가 내려갔으면 저장소 루트에서 `docker compose -f sat-job-local/compose.yaml up -d --build`로 시작한다.
- [저장된 On-Demand 생성 화면](http://127.0.0.1:8080/reference/job-new.html), [저장된 Spot 생성 화면](http://127.0.0.1:8080/reference/job-spot.html), [로컬 입력 화면](http://127.0.0.1:8080/local#assets)을 연다. 저장 화면의 선택 목록은 SCP 사설 백엔드와 연결되지 않으므로 **화면 읽기와 설정표 작성**에 사용한다.
- `학습 형태`, `Job Failover`, `리소스`, `노드`, `이미지`, `Command`, `Volume/Object Storage`를 가리킬 수 있는지 확인한다. 교육생이 실수로 `생성`을 누르지 않도록 3·4차수는 **제출 전 검토**로 안내한다.
- 강사가 시연할 두 Job의 평가값은 실제 보존 결과다. 텍스트 test 700건 정확도 16.0%→85.29%, 이미지 test 2,000건 11.2%→86.2%. 과거 GPU 사용률 시계열은 가져오지 않았으므로 모니터링 탭의 부재를 그대로 설명한다.
