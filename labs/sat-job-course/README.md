# SAT Training Job 녹화 강의

SAT 중심의 **20분 영상 8편(총 160분)** 제작 원고다. 이전 과정은 [백업 과정](../sat-8h/)에 그대로 보존한다. 영상에는 강사의 연속 설명과 화면 시연만 넣는다. 개별 실습·토의·발표는 러닝타임에 포함하지 않는다.

| 파일 | 용도 |
|---|---|
| [CURRICULUM.md](CURRICULUM.md) | 차수별 고유 주제와 중복 방지 기준 |
| [TEACHING_GUIDE.md](TEACHING_GUIDE.md) | 5분 구간별 녹화 대본·화면 동작 |
| [SLIDE_DECK.md](SLIDE_DECK.md) | 영상용 화면·도표 원고 |
| [SERVICE_COMPARISON.md](SERVICE_COMPARISON.md) | SAT·SageMaker·Bedrock 비교 근거 |

시연 자료는 [로컬 Job 목록](http://127.0.0.1:8080/local#jobs), [원본 demo](http://127.0.0.1:8080/local#jobs/b669419947d55d6991620cdf9bbcaa1f/details), [한국어 텍스트 Job](http://127.0.0.1:8080/local#jobs/2dd8760c5b7b55dc8d440c0d18ad2a4e/details), [이미지 Job](http://127.0.0.1:8080/local#jobs/cb0e433e77965ac9ad283d14027ed2df/details), [On-Demand 폼](http://127.0.0.1:8080/reference/job-new.html), [Spot 폼](http://127.0.0.1:8080/reference/job-spot.html)이다. 로컬 사이트는 교육용 구현이고, 보존된 결과는 AWS G6 실행 기록이다. 이 과정의 녹화 시연에서 새 GPU Job이나 EC2를 생성하지 않는다.
