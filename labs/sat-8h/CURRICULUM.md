# SAT Training Job 커리큘럼: 20분 × 8차수

총 **160분(2시간 40분)**이다. 1~4차수와 5~8차수에서 각각 **이론 1차수 → 실습 3차수**로 진행한다. 이론은 scp_sat_videos의 음성 전사본에서 SAT Job 관련 발화를 근거로 구성한다. 실습은 검증한 한국어 텍스트 분류와 이미지 분류 Job의 입력, 설정, 로그, 결과를 사용한다.

| 차수 | 시간 | 구분 | 내용 | 학습자가 확인할 결과 |
|---:|---:|---|---|---|
| 1 | 0–20분 | 이론 | SAT Training Job의 입력, 컨테이너 이미지, 명령, GPU, 로그, 출력 흐름 | Job 구성도와 입력·출력 경로 |
| 2 | 20–40분 | 실습 | 로컬 사이트에서 원본 demo Job 상세·로그·결과 파일 확인 | demo 입력과 출력 파일 목록 |
| 3 | 40–60분 | 실습 | 한국어 YNAT 데이터, 라벨, 분할, 샘플 JSONL·매니페스트 확인 | 텍스트 Job 입력과 데이터 검증 기록 |
| 4 | 60–80분 | 실습 | 텍스트 Job 설정·로그·학습 전후 정확도와 macro-F1·저장 모델 확인 | 텍스트 비교 결과와 해석 |
| 5 | 80–100분 | 이론 | 온디맨드·스팟 선택, Job 중단 가능성, 모니터링·로그·체크포인트·결과 저장 | 이미지 Job 운영·확인 항목표 |
| 6 | 100–120분 | 실습 | Fashion-MNIST 이미지·한국어 라벨·샘플 PNG·매니페스트 확인 | 이미지 Job 입력과 데이터 검증 기록 |
| 7 | 120–140분 | 실습 | 이미지 Job 설정·로그·학습 전후 정확도와 macro-F1·모델 파일 확인 | 이미지 비교 결과와 해석 |
| 8 | 140–160분 | 실습 | 두 Job의 상세·모니터링·로그·평가 비교·결과 파일 대조 및 종료 절차 확인 | 결과 보고서와 자원 삭제 확인 항목 |

## 이론의 음성 전사 근거

- **1차수:** `SCP Simple AI Training 상품설명회 영상_261027_audio_only.txt` 00:09–02:02(관리형 학습의 목적), 02:02–03:20(데이터·학습 코드·컨테이너 이미지와 GPU Job), 06:17–07:16(설정·데이터 이동·결과 저장). 보조 자료는 `[KR] AI워크로드를 위한 SCP GPUaaS 아키텍처 설계_2610_audio_only.txt` 03:36–07:48이다.
- **5차수:** 같은 SAT 상품설명회 전사 03:20–05:08(온디맨드·스팟), 08:12–10:07(Job 설정·ServiceWatch·대기/취소)과 GPUaaS 전사 12:07–14:18(스팟 중단·체크포인트), 15:29–17:35(이미지·명령·스토리지·모니터링)을 사용한다.
- 두 전사본은 음성 자동 전사를 영상 일부와 대조해 수정한 자료다. 제품의 현재 기능·가격·출시 여부를 확인하는 공식 문서로 취급하지 않는다. 특히 **스팟 중단 후 자동 재개와 Failover 제공 범위는 전사만으로 확정하지 않는다.** 실습 화면에서 확인한 설정과 실제 실행 결과를 구분해 설명한다.
- CNN, 이미지 정규화, 정확도, macro-F1의 정의는 이 음성 자료의 직접 설명 범위 밖이다. 6~7차수에서는 실습 코드·데이터·측정 결과에 붙여 필요한 만큼 설명한다.
차수별 실제 진행 대본과 학습자 실습 절차는 [TEACHING_GUIDE.md](TEACHING_GUIDE.md)에 있다.

## 실습 자료와 운영 범위

- 원본 demo와 텍스트·이미지 G6 검증 결과는 로컬 사이트의 **Training Job 목록**에서 확인한다.
- 텍스트와 이미지 실습 코드는 이 폴더의 train_text.py, train_image.py, prepare.py에 있다.
- owasp-llm-lab-setup-guide/examples/llm03의 원본 LoRA 실험은 별도 심화·강사 시연 자료다. 8차수의 필수 실습에는 포함하지 않는다.
- G6에서 학습을 재실행하면 종료 후 Terraform 자원과 EC2/EBS 삭제 여부를 확인한다. 저장된 결과를 읽는 수업에서는 신규 인스턴스를 만들 필요가 없다.

## 수료 확인

- 두 Job의 입력 데이터, 실행 설정, 로그, 학습 전후 지표, 출력 모델을 설명할 수 있다.
- 정확도와 macro-F1의 실제 측정값을 사용해 결과를 해석하고, AWS G6 검증 결과와 SCP SAT 제품 실행을 구분한다.
